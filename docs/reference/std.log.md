# std.log

`std.log` は値を処理系のログ出力に流す。

- 種別：std の演算
- 作用：ログ（writer モナドに対応する。結合は既定ハンドラが列への追記として与えるので、モノイドの定義は要らない）

## 構文

```yaml
- $std.log: 式
```

## 規則

- 既定ハンドラは値をホストのログ出力（標準エラー出力など、評価結果の文書とは別の場所）へ流す。
- 値は null である（YAML に unit 型がないため、null を unit の代用とする）。`$do` の文の位置に置くのがなじむ。
- ログを文書の中で受け取ったり、加工して流し直したりするには、`std.log` の節を持つ [$handler](handler.md) を立てる。

## 例

```yaml
$do:
- $std.log: computing
- 42
```

```yaml
42
```

ログ出力には `computing` が流れる。

## 関連

- [$handler](handler.md)（ログの捕捉と計装）
