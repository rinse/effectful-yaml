# $fn

`$fn` は関数の値（閉包）を作る。
呼び出しは、レキシカルな束縛（`$.名前`）、演算（`$名前空間.名前`）、予約キー（`$名前`）の三形が同じ `{$名前: 引数}` の形を共有する。

- 種別：関数（作用を持たない。呼び出しの作用は本体に由来する）
- 補助キー：`$body`

## 形

```yaml
$fn: パラメータ名
$body: 式
```

## 規則

- 評価すると、定義位置の束縛を捕まえた閉包になる。
- パラメータはちょうど一つに固定する。Kleisli 合成 `>=>` で合成できるのは一引数の関数だけだからである。複数の値はマッピングで一つに包み、本体から `${arg.名前}` のようにパスで参照する。
- 閉包が作用境界の外へ出て文書の値に残ることはエラーである。
- `$let` で束縛した関数は `{$.名前: 引数}` で呼ぶ。引数を評価してからパラメータに束縛し、本体を定義位置の環境で評価する（レキシカルスコープ）。
- 呼び出しの作用は、引数の作用と本体の作用の合併である。
- `$let` が非再帰なので、名前による再帰は書けない。反復は `std.each` と `$collect` のようにデータ構造に沿った形で書く。

## 呼び出しと名前空間

呼び出しの名前は形で三つに分かれ、解決の優先順位のような暗黙の規則を持たない。

| 形 | 指すもの |
|---|---|
| `$.名前` `$.名前.名前…` | レキシカルな束縛（ローカル名前空間） |
| `$名前空間.名前` | 演算（`std.` なら標準演算、それ以外ならホスト登録演算） |
| `$名前` | 予約キー（ドットを含まない、言語が予約する 17 個） |

- **`$.名前`**：名前はドット区切りの単純な識別子の列（`名前(.名前)*`）である。最初の区画が束縛を解決し、残りの区画があればその値のマッピングを順にキーでたどる。たどり着いた値が関数でなければエラーになる。添字 `[0]` はこの経路では書けない。添字の先や、計算した式の先にある関数を呼びたいときは [$pipe](pipe.md) に式として渡す。
- 三形は名前の形（先頭のドットの有無、ドットを含むかどうか）だけで一意に決まる。`$let` の束縛名にドットを使えないため、名前の中のドットは常に、束縛名が終わりキーアクセスが始まる区切りとして読める。
- 呼び出しの経路の解決に失敗した場合は、失敗作用ではなくエラーの語彙（`undefined reference`、`cannot access key`、`missing key`）で報告する。関数という文書の形に関わる誤りだからである。
- `${x}` の参照は呼び出しではないので、この規則の対象外である。

## 例

```yaml
$do:
- $let:
    double:
      $fn: x
      $body: ${x * 2}
- {$.double: 21}
```

```yaml
42
```

束縛の値がマッピングなら、ドットで区切ったパスでその中の関数を直接呼べる。

```yaml
$do:
- $let:
    helpers:
      double:
        $fn: x
        $body: ${x * 2}
- {$.helpers.double: 21}
```

```yaml
42
```
