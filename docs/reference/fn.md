# $fn

`$fn` は関数の値（閉包）を作る。
呼び出しは、レキシカルな束縛（`$.名前`）、演算（`$名前空間.名前`）、予約キー（`$名前`）の三形が同じ `{$名前: 引数}` の形を共有する。

- 種別：関数（作用を持たない。呼び出しの作用は本体に由来する）
- 補助キー：`$body`

## 形

```yaml
$fn: パラメータ名
$body: 式
```

```yaml
$fn: [パラメータ名, パラメータ名, ...]
$body: 式
```

## 規則

- 評価すると、定義位置の束縛を捕まえた閉包になる。
- カーネルの関数はパラメータをちょうど一つに固定する。Kleisli 合成 `>=>` で合成できるのは一引数の関数だけだからである。複数の値はマッピングで一つに包み、本体から `${arg.名前}` のようにパスで参照する。
- 閉包が作用境界の外へ出て文書の値に残ることはエラーである。
- `$let` で束縛した関数は `{$.名前: 引数}` で呼ぶ。引数を評価してからパラメータに束縛し、本体を定義位置の環境で評価する（レキシカルスコープ）。
- 呼び出しの作用は、引数の作用と本体の作用の合併である。
- `$let` が非再帰なので、名前による再帰は書けない。反復は `std.each` と `$collect` のようにデータ構造に沿った形で書く。
- 関数値の自己適用（引数を通じて自分自身に到達しうる適用）は、評価前の関数値の流れの検査が拒否する（[言語仕様](../grammar.md)の「関数値の流れと停止性」）。
- `{$fn: x, $let: 束縛, $body: 式}` の `$let` は前置きであり、`$fn` 全体を包む（[$do](do.md) の前置き）。束縛は関数の外で一度だけ評価され、`x` は束縛の右辺から見えない。

## 引数名の列と部分適用

`$fn` には相異なる名前の列（1 個以上）も書ける。
この形は導出形であり、意味はカリー化の展開で定める。

```
{$fn: [a, b, ...残り], $body: 本体} ≡ {$fn: a, $body: {$fn: [b, ...残り], $body: 本体}}
{$fn: [a], $body: 本体}            ≡ {$fn: a, $body: 本体}
```

- **部分適用**は通常の適用である。先頭の引数だけを与える呼び出しは、残りの引数を待つ閉包を返す。
- 引数の式はその適用の位置で正格に評価され、値が閉包に捕まり、再評価されない。引数の式の作用は部分適用の位置で一度だけ生じ、本体の作用は最後の引数が与えられて本体が走る位置で生じる。
- 空の列、文字列でない要素、名前の重複は形の誤りでありエラーになる。
- ハンドラの節と `$collect` の `$with` は処理系が一引数で呼ぶ位置なので、そこに引数 2 個以上の `$fn` を書くと閉包が結果の値になり、多くの場合そのまま関数値の脱出のエラーへ至る。
- マッピング引数の演算を部分適用するには、引数を組み立てるカリー化された関数（adapter）を `$let` で一度宣言する。

## 呼び出しと名前空間

呼び出しの名前は形で三つに分かれ、解決の優先順位のような暗黙の規則を持たない。

| 形 | 指すもの |
|---|---|
| `$.名前` `$.名前.名前…` | レキシカルな束縛（ローカル名前空間） |
| `$名前空間.名前` | 演算（`std.` なら標準演算、それ以外ならホスト登録演算） |
| `$名前` | 予約キー（ドットを含まない、言語が予約する 14 個） |

- **`$.名前`**：名前はドット区切りの単純な識別子の列（`名前(.名前)*`）である。最初の区画が束縛を解決し、残りの区画があればその値のマッピングを順にキーでたどる。束縛を導入するのは [$let](let.md) と `$fn`、および `$with` のローカル作用の宣言（[$with](with.md)）である。たどり着いた値が関数でなければエラーになる。添字 `[0]` はこの経路では書けない。添字の先や、計算した式の先にある関数は、[$let](let.md) で名前に束縛してから `$.名前` で呼ぶ。
- 三形は名前の形（先頭のドットの有無、ドットを含むかどうか）だけで一意に決まる。`$let` の束縛名にドットを使えないため、名前の中のドットは常に、束縛名が終わりキーアクセスが始まる区切りとして読める。
- 最初の区画が `return` である呼び出し（`$.return` と `$.return.x` を含む）は形の誤りであり、評価前に `return is reserved: $.return is not callable` で拒否される。`return` は [$with](with.md) の節名として予約されており、`$with` の `return` は return 節であって束縛を導入しないので、この呼び出しは決して解決しない。`return` という名前への束縛と `${return}` の参照は妨げない。
- 呼び出しの経路の解決に失敗した場合は、失敗作用ではなくエラーの語彙（`undefined reference`、`cannot access key`、`missing key`）で報告する。関数という文書の形に関わる誤りだからである。
- `${x}` の参照は呼び出しではないので、この規則の対象外である。

## 例

```yaml
$do:
- $let:
    double:
      $fn: x
      $body: ${x * 2}
- {$.double: 21}
```

```yaml
42
```

束縛の値がマッピングなら、ドットで区切ったパスでその中の関数を直接呼べる。

```yaml
$do:
- $let:
    helpers:
      double:
        $fn: x
        $body: ${x * 2}
- {$.helpers.double: 21}
```

```yaml
42
```

引数名の列は部分適用の経路を開く。
表を固定した照会関数を作る。

```yaml
$do:
- $let:
    codes: {ja: 81, us: 1}
    look:
      $fn: [m, k]
      $body:
        $std.lookup:
          in: ${m}
          key: ${k}
- $let:
    dial:
      $.look: ${codes}
- $.dial: ja
```

```yaml
81
```
