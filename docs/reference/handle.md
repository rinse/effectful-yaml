# $handle

`$handle` は利用者が定義するハンドラであり、カーネルが持つ唯一のハンドラである。
std の派生ハンドラ（`$std.list` や `$std.state` など）はすべて、`$handle` と `$collect` への展開として定義される。

- 種別：ハンドラ
- 処理する作用：`$with` の節に書いた演算
- 補助キー：`$with` `$resume`（`$resume` は節の本体でだけ使える呼び出し）

## 形

```yaml
$handle: 本体の式
$with:
  演算名:
    $fn: 引数名
    $body: 節の本体
  return:
    $fn: 値名
    $body: 式
```

## 規則

- `$with` の節のキーは、ドットを含む演算名そのもの（`std.fail` や `vault.read` など）か、予約された節名 `return` である。
- 本体で節の演算が呼ばれると、演算の引数が節のパラメータに束縛され、節の本体が評価される。
- 節の本体では `{$resume: 値}` で継続を再開できる。その値は、演算の呼び出し位置に「値」を返して残りの計算（`return` 節を含む）を進めた結果である。
- `$resume` は節の本体の中で呼べる。節の本体で作られた閉包の本体も含み、閉包が捕まえるのはその節の起動に対応する継続である。一度も呼ばない（打ち切り）ことも、複数回呼ぶことも許される。
- 節が `$resume` を呼ばずに値に達したときは、その値がハンドラ全体の値になる（打ち切り）。継続の途中で打ち切られた場合は、その継続を呼んだ `$resume` の位置ではなく、ハンドラ全体が節の値になる。
- ハンドラは深い。再開後の計算にも同じハンドラが効き続ける。
- 節の本体が起こす作用は、このハンドラ自身ではなく外側で処理される。
- `return` 節は、本体が演算を起こさず値に達したときにその値を変換する。省略時は恒等である。
- 作用の推論では、`$with` に現れた演算の名前が集合から除かれ、節と `return` の本体の作用が加わる。

## 節名

節のキーは演算名そのものである。

| 作用 | 節名 |
|---|---|
| 選択 | `std.each`（`$std.where` は演算ではなく、`std.each` への展開で処理される） |
| パラメータ | `std.param` |
| 状態 | `std.get` `std.set` |
| ログ | `std.log` |
| 失敗 | `std.fail` |
| 登録演算 | `vault.read` のようにドット入りのまま |

捕捉の単位は作用ではなく演算である。
`std.get` だけを捕まえて `std.set` を素通しにすることもできる。
節に書かなかった演算は外側のハンドラへ抜ける。

## 節の中の閉包から $resume を呼ぶ

節の本体は、その中で作った関数値の本体からも `$resume` を呼べる。
この規則がなければ、`$collect` の `$with` に渡す関数の中から継続を再開する書き方が書けない。

[std.list](std.list.md) の展開がこの規則の具体例である。
`std.each` の節は、選ばれうる要素の列を `$collect` で回り、その `$with` 関数の本体（節の本体が作った閉包）の中で `$resume: ${x}` を呼ぶ。
閉包が捕まえる継続は、`std.each` の節が起動された時点のものであり、`$collect` が要素ごとにこの閉包を呼ぶたびに、同じ継続をその要素の値で再開する。

## 失敗の捕捉

失敗を捕捉し、ログを流して既定値に置き換える。

```yaml
port:
  $handle:
    $do:
    - $let:
        p: {$std.param: port, $default: 0}
    - $if: ${p <= 0}
      $then:
        $std.fail: invalid port ${p}
      $else: ${p}
  $with:
    std.fail:
      $fn: msg
      $body:
        $do:
        - $std.log: ${msg}
        - 5432
```

`port` を渡さずに評価すると次になり、ログに `invalid port 0` が流れる。

```yaml
port: 5432
```

## ログの計装

演算を捕捉し、加工してから同じ演算を呼び直す転送の形である。
節の本体で起こした `std.log` は自分では捕まらず、外側で処理される。

```yaml
$handle:
  $do:
  - $std.log: hello
  - 42
$with:
  std.log:
    $fn: msg
    $body:
      $do:
      - $std.log: 'app: ${msg}'
      - {$resume: null}
```

結果は `42` で、外のログには `app: hello` が流れる。
`std.log` の値は null なので、null で再開している。

## std の派生ハンドラとの関係

`$std.list`、`$std.mapping`、`$std.first`、`$std.state`、`$std.opt` はいずれも `$handle`（`$std.first` はさらに内部の私的な状態も）で書ける形の言語組み込みの省略である。
利用者が独自の選択の集約や、独自の状態の持ち回りを書きたいときは、`$handle` を直接使う。
組み込みの展開は各ページに掲載してあるので、自作するときの雛形として読める。
