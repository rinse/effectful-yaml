# $handle

`$handle` は利用者が定義するハンドラである。
本体の中で節に書いた演算が呼ばれると、対応する節が評価される。

- 種別：ハンドラ
- 処理する作用：`$with` の節に書いた演算
- 補助キー：`$with` `$resume`（`$resume` は節の本体でだけ使える呼び出し）

## 形

```yaml
$handle: 本体の式
$with:
  演算名:
    $fn: 引数名
    $body: 節の本体
  return:
    $fn: 値名
    $body: 式
```

## 規則

- `$with` の節のキーは `$` を付けない演算名である。標準演算は `fail` のようにドットなし、登録演算は `vault.read` のようにドット入りで書く。節名 `return` は予約されている。
- 本体で節の演算が呼ばれると、演算の引数が節のパラメータに束縛され、節の本体が評価される。
- 節の本体では `{$resume: 値}` で継続を再開できる。その値は、演算の呼び出し位置に「値」を返して残りの計算（`return` 節を含む）を進めた結果である。
- `$resume` を一度も呼ばなければ、本体は打ち切られ、節の本体の値がハンドラ全体の値になる。複数回呼ぶことも許される。標準の `$list` はこの機構で実装できる強さである。
- ハンドラは深い。再開後の計算にも同じハンドラが効き続ける。
- 節の本体が起こす作用は、このハンドラ自身ではなく外側で処理される。
- `return` 節は、本体が値に達したときにその値を変換する。省略時は恒等である。
- 作用の推論では、`$with` に現れた演算の作用が集合から除かれ、節と `return` の本体の作用が加わる。

## 節名

節のキーは演算名から `$` を外したものである。

| 作用 | 節名 |
|---|---|
| 選択 | `each` `where` |
| パラメータ | `param` |
| 状態 | `get` `set` |
| ログ | `log` |
| 失敗 | `fail` |
| 登録演算 | `vault.read` のようにドット入りのまま |

捕捉の単位は作用ではなく演算である。
`get` だけを捕まえて `set` を素通しにすることもできる。
節に書かなかった演算は外側のハンドラへ抜ける。

## 失敗の捕捉

失敗を捕捉し、ログを流して既定値に置き換える。

```yaml
port:
  $handle:
    $do:
    - $let:
        p: {$param: port, $default: 0}
    - $if: ${p <= 0}
      $then:
        $fail: invalid port ${p}
      $else: ${p}
  $with:
    fail:
      $fn: msg
      $body:
        $do:
        - $log: ${msg}
        - 5432
```

`port` を渡さずに評価すると次になり、ログに `invalid port 0` が流れる。

```yaml
port: 5432
```

## ログの計装

演算を捕捉し、加工してから同じ演算を呼び直す転送の形である。
節の本体で起こした `$log` は自分では捕まらず、外側で処理される。

```yaml
$handle:
  $do:
  - $log: hello
  - 42
$with:
  log:
    $fn: msg
    $body:
      $do:
      - $log: 'app: ${msg}'
      - {$resume: null}
```

結果は `42` で、外のログには `app: hello` が流れる。
`$log` の値は null なので、null で再開している。

## $list の自作

複数回の再開の例として、`$list` はこの機構で自作できる。

```yaml
$handle:
  $do:
  - $let:
      x: {$each: [1, 2]}
      y: {$each: [10, 20]}
  - ${x + y}
$with:
  each:
    $fn: xs
    $body:
      $list:
        $do:
        - $let:
            e:
              $each: ${xs}
            part:
              $resume: ${e}
            r:
              $each: ${part}
        - ${r}
  return:
    $fn: v
    $body:
    - ${v}
```

結果は組み込みと同じ `[11, 21, 12, 22]` である。
節は要素 e を選ぶたびに `$resume` を呼ぶ。
ハンドラは深いので、残りの計算の `$each` も再帰的にこの節が処理し、`$resume` は常に「残りの全結果のリスト」を返す。
`return` 節が末端の値を要素 1 のリストに包み、節は各 part を `$each` の二段選択で平坦化して、節内の `$list` が連結順に集める。
連結の式演算はまだ無いが、このように入れ子の選択で代用できる。
実用では組み込みの `$list` を使う。
