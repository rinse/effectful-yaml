# $op

`$op` は演算を関数の値として参照する。
`{$op: 演算名}` は η 展開 `{$fn: x, $body: {$演算名: ${x}}}` と等価な導出形であり、短縮と意図の明示のためにある。

- 種別：関数（作用を持たない。参照した演算の作用は呼び出し時に起こる）

## 形

```yaml
{$op: 演算名}
```

## 規則

- 対象は演算だけである。演算名は必ずドットを含む。`std.` で始まる名前は標準演算（`std.each` など）を、それ以外はホストに登録された演算（`vault.read` など）を指す。
- `$do` のような構文と std の派生ハンドラ（`$std.list` など）は参照できない。演算が呼び出しのキーの位置にしか現れられず、式 `${...}` ではパスアクセスの記法と衝突して名指しできないために、`$op` という専用の形を置く。
- レキシカルな束縛は `${名前}` で値として参照できるので、`$op` の対象外である。
- 値は一引数の関数であり、`$pipe` の段に置いたり `$let` で束縛したりできる。

## 例

`$pipe` の段に演算を置く。

```yaml
$do:
- $let:
    upper: {$op: std.upper}
- $pipe: hello
  $through:
  - ${upper}
```

```yaml
HELLO
```

長い名前の登録演算に短いローカル名を付ける慣用にも使う。

```yaml
$do:
- $let:
    read: {$op: vault.secrets.read}
- {$.read: db/password}
```

`vault.secrets.read` が登録されていれば、`{$vault.secrets.read: db/password}` と同じ意味になる。
