# $get

`$get` はセルの現在値を読む。

- 種別：演算
- 作用：状態（state モナドに対応する）

## 形

```yaml
{$get: セル名}
```

## 規則

- 最も近い `$state` の記憶からセルを読む。文書の最外には暗黙の `$state: {}` がある。
- 未作成のセルの読み出しはエラーになる。「暗黙の null を作らない」原則による。
- セルの名前空間は `$let` の束縛とは別である。同名でも互いに関係しない。
- 選択に対する位置が意味を持つ。`$each` より前の `$get` は分岐する前に一度だけ実行され、全分岐が同じ値を見る。後なら分岐ごとに読み直される。

## 例

```yaml
$do:
- $set: {n: 41}
- $let:
    v: {$get: n}
- ${v + 1}
```

```yaml
42
```
