# $each

`$each` は要素を一つずつ選ぶ。
list モナドの bind に相当し、ブロックを要素の数だけ分岐させる。

- 種別：演算
- 作用：選択

## 形

```yaml
{$each: リストまたはマッピングの式}
```

## 規則

- 引数を評価した結果がリストなら各要素を、マッピングなら各エントリを `{key: キー, value: 値}` の形で、文書順に一つずつ選ぶ。値は選ばれた要素である。
- それ以外の型はエラーになる。
- `$each: ${xs}` のように、データ駆動の反復が書ける。
- 空のリストやマッピングは分岐 0 本を意味し、`$where: false` と同じく打ち切りになる。
- 選択が処理されずに残った作用境界は、全分岐の結果を文書順に並べたリストに評価される。
- 典型的には `$let` の右辺に置き、`x: {$each: [a, b, c]}` を「a、b、c のそれぞれを x として」と読む。

## 例

```yaml
$do:
- $let:
    x: {$each: [1, 2]}
    y: {$each: [10, 20]}
- ${x + y}
```

```yaml
[11, 21, 12, 22]
```

マッピングの分解は次のとおりである。

```yaml
$do:
- $let:
    e: {$each: {web: 80, db: 5432}}
- ${e.key}
```

```yaml
[web, db]
```
