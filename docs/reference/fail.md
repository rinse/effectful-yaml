# $fail

`$fail` は計算を失敗させる。

- 種別：演算
- 作用：失敗

## 形

```yaml
$fail: 式
```

## 規則

- 引数の値をエラーメッセージとして、計算をその場で打ち切り失敗させる。
- 既定ハンドラは失敗を文書全体のエラーにする。
- `$first` の中では、失敗した分岐が捨てられて次の分岐に進む。
- `$handle` で `fail` を捕捉すれば、失敗から回復できる。
- `$list` と `$mapping` は失敗を処理しない。一つの分岐の失敗が全体の失敗になる。
- 失敗と打ち切りは違う。`$where` は分岐を静かに消すが、`$fail` は処理されない限りエラーとして残る。

## 例

`port` を渡さずに評価すると、`invalid port 0` を理由に文書全体がエラーになる。

```yaml
$do:
- $let:
    p: {$param: port, $default: 0}
- $if: ${p <= 0}
  $then:
    $fail: invalid port ${p}
  $else: ${p}
```
