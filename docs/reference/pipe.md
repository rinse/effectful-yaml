# $pipe

`$pipe` は値を関数の列に順に通す。
Kleisli 合成 `f >=> g >=> h` の具体形である。

- 種別：関数（作用を持たない。各段の作用は通過時に起こる）
- 補助キー：`$through`

## 形

```yaml
$pipe: 式
$through:
- 関数値の式
- 関数値の式
```

## 規則

- `$pipe` の値を最初の関数に渡し、その結果を次の関数に渡すことを繰り返す。最後の結果が全体の値になる。
- 空の `$through` は先頭の値をそのまま返す。
- 段には関数値の式を置く。`${double}` のような単純な参照、`${arg.step}` のようなパスをたどる参照、インラインの `$fn`、`{$op: 演算名}` のいずれでもよい。`$.名前` の呼び出しがマッピングのキーをドットでたどる形（`$.helpers.double` など）に限られるのに対し、`$pipe` は添字や計算した式の先にある関数も呼べる。
- 全体の作用は、先頭の式と各段の作用の合併である。

## 例

```yaml
$do:
- $let:
    double:
      $fn: x
      $body: ${x * 2}
    succ:
      $fn: x
      $body: ${x + 1}
- $pipe: 20
  $through:
  - ${double}
  - ${succ}
```

```yaml
41
```
