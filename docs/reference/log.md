# $log

`$log` は値を処理系のログ出力に流す。

- 種別：演算
- 作用：ログ（writer モナドに対応する。結合は既定ハンドラが列への追記として与えるので、モノイドの定義は要らない）

## 形

```yaml
- $log: 式
```

## 規則

- 既定ハンドラは値を処理系のログ出力（標準エラー出力など、評価結果の文書とは別の場所）へ流す。
- 文としての値は null である。
- ログを文書の中で受け取りたい場合は、`$handle` で `log` を捕捉する。

## 例

```yaml
$do:
- $log: computing
- 42
```

```yaml
42
```

ログ出力には `computing` が流れる。
