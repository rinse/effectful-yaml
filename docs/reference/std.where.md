# std.where

`$std.where` は条件を満たさない分岐を打ち切る。
リスト内包表記のガードに相当する。

- 種別：導出形（`std` 名前空間）
- 作用集合への寄与：`std.each`（展開のとおり）

## 形

```yaml
- $std.where: 条件式
```

## 展開

`$std.where` は演算ではなく導出形であり、意味は次の展開で定める。

```
{$std.where: 条件式} ≡ {$if: 条件式, $then: null, $else: {$std.each: []}}
```

空のリストの `$std.each` は分岐 0 本の選択であり、包囲する選択のその分岐を打ち切る（[std.each](std.each.md) の規則）。

## 規則

- 条件が偽なら、その分岐は打ち切られて結果に何も残さない（null が残るのではない）。真なら何もしない。
- 条件は真偽値でなければならない。
- 文としての値は null である。
- 演算ではないので、ハンドラの節の名前にならず、捕捉もされない。打ち切りを処理するのは、展開に現れる `std.each` を処理する選択のハンドラである。
- 打ち切りは失敗ではない。`std.fail` が全体を失敗させるのに対し、`$std.where` は分岐を静かに消す。
- `$std.mapping` の本体で使えば、条件を満たすエントリだけを持つマッピングが作れる。

## 例

```yaml
$std.list:
  $do:
  - $let:
      x: {$std.each: [1, 2, 3]}
      y: {$std.each: [1, 2, 3]}
  - $std.where: ${x < y}
  - - ${x}
    - ${y}
```

```yaml
[[1, 2], [1, 3], [2, 3]]
```
