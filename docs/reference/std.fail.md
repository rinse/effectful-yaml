# std.fail

`std.fail` は計算を失敗させる。

- 種別：標準演算
- 作用：失敗

## 形

```yaml
$std.fail: 式
```

## 規則

- 引数の値をエラーメッセージとして、計算をその場で打ち切り失敗させる。
- 既定ハンドラは失敗を文書全体のエラーにする。
- `$std.first` の中では、失敗した分岐が捨てられて次の分岐に進む。
- `$handle` で `std.fail` を捕捉すれば、失敗から回復できる。
- `$std.list` と `$std.mapping` は失敗を処理しない。一つの分岐の失敗が全体の失敗になる。
- 失敗と打ち切りは違う。`std.where` は分岐を静かに消すが、`std.fail` は処理されない限りエラーとして残る。

## データ起因の部分性も同じ失敗になる

明示の `$std.fail` 呼び出しのほかに、次のデータ起因の部分性もすべて `std.fail` を起こす。

- パスをたどる参照（`${x.y}` や `${xs[0]}`）でキーや添字が存在しないとき。
- `std.param` で渡されていないパラメータを、`$default` なしで読んだとき。
- `std.get` で未初期化のセルを読んだとき。

これらは、束縛名そのものが未定義であることや型の不一致のような**文書の形の誤り**とは区別される。
文書の形の誤りは捕捉できないエラーのままだが、データ起因の部分性は `std.fail` に統一されているので、`$handle` や `$std.opt` で一律に回復できる。

## 例

`port` を渡さずに評価すると、`invalid port 0` を理由に文書全体がエラーになる。

```yaml
$do:
- $let:
    p: {$std.param: port, $default: 0}
- $if: ${p <= 0}
  $then:
    $std.fail: invalid port ${p}
  $else: ${p}
```
