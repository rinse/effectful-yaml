# std.get

`std.get` はセルの現在値を読む。

- 種別：標準演算
- 作用：状態（state モナドに対応する）

## 形

```yaml
{$std.get: セル名}
```

## 規則

- 最も近い `$std.state` の記憶からセルを読む。文書の最外には暗黙の `$std.state: {}` がある。
- 未作成のセルの読み出しは `std.fail` を起こす。「暗黙の null を作らない」原則による。この失敗は [std.state](std.state.md) の展開の節の本体で起こるので、そのセルを解決する状態ハンドラの位置で生じる。暗黙の既定状態は境界にあるため、文書内で捕捉するには、明示の `$std.state` を捕捉するハンドラの内側に置く（`$std.opt` の内側に `$std.state` を書けば捕まり、逆の入れ子では捕まらない）。
- セルの名前空間は `$let` の束縛とは別である。同名でも互いに関係しない。
- 選択に対する位置が意味を持つ。`std.each` より前の `std.get` は分岐する前に一度だけ実行され、全分岐が同じ値を見る。後なら分岐ごとに読み直される。

## 例

```yaml
$do:
- $std.set: {n: 41}
- $let:
    v: {$std.get: n}
- ${v + 1}
```

```yaml
42
```
