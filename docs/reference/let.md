# $let

`$let` は値に名前を束縛する。
右辺が作用を起こしてよいので、Haskell の `x <- ...` に相当する束縛も兼ねる。

- 種別：束縛と制御（作用を持たない構文）

## 形

```yaml
- $let:
    x: 式1
    y: 式2
```

## 規則

- `$do` の文としてだけ書ける。文としての値は null である。
- 右辺を文書順に評価し、値を名前に束縛する。ブロックの残りの文から `${x}` で参照できる。
- 後の束縛の右辺からは先の束縛を参照できる。
- 非再帰である。右辺から自分自身や後の束縛は見えない。
- 同じ名前の再束縛は許され、外側の束縛を隠す。
- 束縛名にドットは使えない。呼び出しの名前空間の区切りと衝突するからである。
- 関数を束縛した場合、`{$.名前: 引数}` で呼べる。
- 右辺が作用を起こす場合、束縛を書く順序は意味を持つ。とりわけ `$each` より前に書いた `$get` は分岐する前に一度だけ実行され、全分岐が同じ値を見る。

## 例

```yaml
$do:
- $let:
    x: 2
    y: ${x + 1}
- ${x * y}
```

```yaml
6
```
