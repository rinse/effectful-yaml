# $let

`$let` は値に名前を束縛し、`$in` の本体を評価する。
逐次のカーネル構文であり、右辺が作用を起こしてよいので bind 相当を兼ねる。

- 種別：束縛と制御（作用を持たない構文）

## 形

```yaml
$let:
  x: 式1
  y: 式2
$in: 本体の式
```

## 規則

- 右辺を文書順に評価し、その値を名前に束縛して、`$in` の本体を評価する。本体の値が全体の値であり、束縛は本体から `${x}` で参照できる。
- 評価の規則は関数呼び出しの規則と同一である。右辺は値渡しで評価され、本体はレキシカルスコープで評価され、作用は右辺と本体の合併である。
- 後の束縛の右辺からは先の束縛を参照できる。
- 非再帰である。右辺から自分自身や後の束縛は見えない。
- 同じ名前の再束縛は許され、外側の束縛を隠す。
- 束縛名にドットは使えない。呼び出しの名前空間の区切りと衝突するからである。
- 関数を束縛した場合、`{$.名前: 引数}` で呼べる。
- 右辺が作用を起こす場合、束縛を書く順序は意味を持つ。とりわけ `std.each` より前に書いた `std.get` は分岐する前に一度だけ実行され、全分岐が同じ値を見る。
- 値を捨てて作用だけを残したい右辺は、`_` のような参照しない名前に束縛する慣用で書く。`_` はただの束縛名であり、特別扱いはない。YAML は一つのマッピング内の重複キーを許さないので、捨てる文が二つ以上あるときは名前を変えるか [$do](do.md) で書く。
- `$in` を省いた `$let` は `$do` の文としてだけ書ける。文としての値は null であり、束縛はブロックの残りの文から見える。

## 例

```yaml
$let:
  x: 2
  y: ${x + 1}
$in: ${x * y}
```

```yaml
6
```
