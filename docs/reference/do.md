# $do

`$do` は文の並びを先頭から順に評価するブロックであり、do 文に相当する。

- 種別：束縛と制御（作用を持たない構文）

## 形

```yaml
$do:
- 文1
- 文2
- 結果式
```

## 規則

- 直下のリストを文の並びとして先頭から評価し、最後の文の値をブロックの値とする。
- 「リストはデータ」の唯一の例外がこの直下のリストである。文の位置に書いた literal なリストは、通常どおりデータとして評価される。
- 空の `$do` の値は null である。
- `$let` と `$where` と `$set` と `$log` は文としては null に評価される。ブロックの結果にしたい値は最後の文に書く。
- 入れ子の `$do` は作用境界にならず、単なるグループ化である。文が起こした作用は最も外側の `$` 式まで伝播する。

## 例

```yaml
$do:
- $log: starting
- hello, world
```

```yaml
hello, world
```
