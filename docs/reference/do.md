# $do

`$do` は文の並びを先頭から順に評価するブロックである。
[$let](let.md)・[$std.state](std.state.md)・[$handle](handle.md) への展開で定まる導出形であり、カーネルには属さない。

- 種別：束縛と制御（導出形）

## 形

```yaml
$do:
- 文1
- 文2
- 結果式
```

## 規則

- 直下のリストを文の並びとして先頭から評価する。任意の式や演算である文は、最後の文なら値をブロックの値とし、それ以外は値を捨てる。
- 本体を欠いた二項形である文は値を持たず、残りの文の並びを自分の本体として包み込む。最後の文に置かれると残りの文の並びが空になるため、その本体は null になる。
- 「リストはデータ」の唯一の例外がこの直下のリストである。文の位置に書いた literal なリストは、通常どおりデータとして評価される。
- 空の `$do` の値は null である。
- 文には任意の式のほか、本体を欠いた二項形（`$in` を省いた `$let` と `$std.state`、単独の `$with`）と演算を置く。`$std.where` と `$std.set` と `$std.log` の値は null であり、この位置に置くのがなじむ。
- 入れ子の `$do` は作用境界にならず、単なるグループ化である。文が起こした作用は最も外側の `$` 式まで伝播する。

## 本体を欠いた二項形

スコープを持つ二項形は本体をちょうど一つ持ち、本体の載る位置は形ごとに定まっている。
本体を欠いて書けば、`$do` の文として置ける。
展開が残りの文をその位置に補う。

| 形 | 本体の位置 | 本体を欠いた形 |
|---|---|---|
| `$let` | `$in` | `$in` を省いた `$let` |
| `$std.state` | `$in` | `$in` を省いた `$std.state` |
| `$handle` | 主キー `$handle` の値 | 単独の `$with` |

`$collect` は本体（継続）を持たないので、文形を持たない。

## 展開

意味は次の展開で定める。
規則は上から順に、最初に一致したものを適用する。
私的名は文書から参照できない捨て名である。

```
{$do: []}                              ≡ null
{$do: [{$let: 束縛}, 残り...]}         ≡ {$let: 束縛, $in: {$do: [残り...]}}
{$do: [{$std.state: 初期値}, 残り...]} ≡ {$std.state: 初期値, $in: {$do: [残り...]}}
{$do: [{$with: 節}, 残り...]}          ≡ {$handle: {$do: [残り...]}, $with: 節}
{$do: [結果]}                          ≡ 結果
{$do: [文, 残り...]}                   ≡ {$let: {私的名: 文}, $in: {$do: [残り...]}}
```

二項形の規則は、本体のキー（`$let` と `$std.state` は `$in`、`$handle` は主キー `$handle` 自身）を欠いた形にだけ一致する。
本体を伴う完全な形（`$in` 付きの `$let` や `$std.state`、`$with` を伴う `$handle`）はどの二項形規則にも一致せず、最後の規則で通常の文として扱われる。

先の文ほど外側のハンドラになる。
`$with` の展開は残りの文全体を `$handle` の本体に包むので、複数の `$with` 文を並べると先に書いた方が外側になる。

## 例

```yaml
$do:
- $std.log: starting
- hello, world
```

```yaml
hello, world
```

単独の `$with` 文で失敗を捕捉する。

```yaml
$do:
- $with:
    std.fail: {$fn: _, $body: 0}
- $std.lookup: {in: {}, key: missing}
```

```yaml
0
```

`$in` を省いた `$std.state` 文と `$let` 文を組み合わせる。

```yaml
$do:
- $std.state: {n: 0}
- $std.set: {n: 41}
- $let:
    n: {$std.get: n}
- ${n + 1}
```

```yaml
42
```
