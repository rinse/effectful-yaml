# $do

`$do` は文の並びを先頭から順に評価するブロックである。
[$let](let.md)・[$std.state](std.state.md)・[$with](with.md) への展開で定まる導出形であり、カーネルには属さない。

- 種別：束縛と制御（導出形）

## 形

```yaml
$do:
- 文1
- 文2
- 結果式
```

## 規則

- 直下のリストを文の並びとして先頭から評価する。任意の式や演算である文は、最後の文なら値をブロックの値とし、それ以外は値を捨てる。
- 文に置いた前置きは値を持たず、残りの文の並びを自分の本体として包み込む。最後の文に置かれると残りの文の並びが空になるため、その本体は null になる。
- 「リストはデータ」の唯一の例外がこの直下のリストである。文の位置に書いた literal なリストは、通常どおりデータとして評価される。
- 空の `$do` の値は null である。
- 文には任意の式のほか、前置き（`$let`、`$std.state`、`$with` の頭だけを書いた形）と演算を置く。`$std.where` と `$std.set` と `$std.log` の値は null であり、この位置に置くのがなじむ。
- 入れ子の `$do` は作用境界にならず、単なるグループ化である。文が起こした作用は最も外側の `$` 式まで伝播する。

## 前置き

スコープを持つ二項形は `$let`、`$std.state`、`$with` の三つであり、それぞれ頭と本体をちょうど一つずつ持つ。
頭は形ごとのキーに、本体は `$in` に書く。
本体を書かずに頭だけを書いた形を**前置き**と呼ぶ。

| 形 | 頭 | 本体 |
|---|---|---|
| `$let` | 束縛（キー `$let`） | `$in` |
| `$std.state` | 初期値（キー `$std.state`） | `$in` |
| `$with` | 節（キー `$with`） | `$in` |

前置きの本体は、それを置いた文脈の残りである。
`$do` の文として置けば残りの文の並びが本体になり、マッピングのキーとして置けば残りのキーからなるマッピングが本体になる。
後者のマッピングを**前置きを持つマッピング**と呼び、残りの形の規則は[言語仕様の評価モデル](../grammar.md)が定める。
残りが `$in` ただ一つならその値が本体になる。
`$with` が頭キーになるのは、同じマッピングに `$collect` が無いときだけであり、あれば `$collect` の補助キーである。

## 展開

意味は次の展開で定める。
規則は上から順に、最初に一致したものを適用する。
私的名は文書から参照できない捨て名である。

```
{$do: []}                              ≡ null
{$do: [{$let: 束縛}, 残り...]}         ≡ {$let: 束縛, $in: {$do: [残り...]}}
{$do: [{$std.state: 初期値}, 残り...]} ≡ {$std.state: 初期値, $in: {$do: [残り...]}}
{$do: [{$with: 節}, 残り...]}          ≡ {$with: 節, $in: {$do: [残り...]}}
{$do: [結果]}                          ≡ 結果
{$do: [文, 残り...]}                   ≡ {$let: {私的名: 文}, $in: {$do: [残り...]}}
```

`$in` や残りを伴う完結した式は前置きの規則に一致せず、最後の規則で通常の文になる。

前置きを持つマッピングの展開は頭ごとに一段である。
本体式は、残りが `{$in: 式}` ならその式、そうでなければ残りのマッピングである。

```
{$let: 束縛} ∪ 残り         ≡ {$let: 束縛, $in: 本体式}
{$std.state: 初期値} ∪ 残り ≡ {$std.state: 初期値, $in: 本体式}
{$with: 節} ∪ 残り          ≡ {$with: 節, $in: 本体式}
```

文でもキーでも、先に書いた前置きほど外側になる。展開が残り全体を本体に包むからである。
前置きの `$let` の束縛と、前置きの `$with` のローカル作用の宣言（ドットを含まない節名）が導入する束縛は、本体すなわち残りから見える（[$with](with.md)）。
マッピングでは頭キー以外のキーの位置は意味を持たず、YAML が重複キーを許さないので各頭キーは一つずつしか置けない。
頭を交互に重ねたいときは `$do` で書く。

## 例

```yaml
$do:
- $std.log: starting
- hello, world
```

```yaml
hello, world
```

文に置いた `$with` の前置きで失敗を捕捉する。

```yaml
$do:
- $with:
    std.fail: {$fn: _, $body: 0}
- $std.lookup: {in: {}, key: missing}
```

```yaml
0
```

文に置いた `$std.state` と `$let` の前置きを組み合わせる。

```yaml
$do:
- $std.state: {n: 0}
- $std.set: {n: 41}
- $let:
    n: {$std.get: n}
- ${n + 1}
```

```yaml
42
```

`$std.list` の直下に `$let` の前置きとレコードのキーを並べると、内包表記になる。

```yaml
$std.list:
  $let:
    x: {$std.each: [1, 2]}
  v: ${x}
```

```yaml
- v: 1
- v: 2
```

残りが `$if` の主形である前置きを持つマッピングを `$std.list` の直下に置く。

```yaml
$std.list:
  $let:
    i0: {$std.each: {$std.range: 15}}
    i: ${i0 + 1}
  $if: ${i % 15 == 0}
  $then: fizzbuzz
  $else:
    $if: ${i % 3 == 0}
    $then: fizz
    $else:
      $if: ${i % 5 == 0}
      $then: buzz
      $else: "${i}"
```

```yaml
[1, 2, fizz, 4, buzz, fizz, 7, 8, fizz, buzz, 11, fizz, 13, 14, fizzbuzz]
```
