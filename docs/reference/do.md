# $do

`$do` は文の並びを先頭から順に評価するブロックである。
[$let](let.md)・[$std.state](std.state.md)・[$with](with.md) への展開で定まる導出形であり、カーネルには属さない。

- 種別：束縛と制御（導出形）

## 形

```yaml
$do:
- 文1
- 文2
- 結果式
```

## 規則

- 直下のリストを文の並びとして先頭から評価する。任意の式や演算である文は、最後の文なら値をブロックの値とし、それ以外は値を捨てる。
- 「リストはデータ」の唯一の例外がこの直下のリストである。文の位置に書いた literal なリストは、通常どおりデータとして評価される。
- 空の `$do` の値は null である。
- 文には任意の式のほか、文脈の導入（`$in` を省いた `$let`、`$std.state`、`$with`）と演算を置く。`$std.where` と `$std.set` と `$std.log` の値は null であり、この位置に置くのがなじむ。
- 入れ子の `$do` は作用境界にならず、単なるグループ化である。文が起こした作用は最も外側の `$` 式まで伝播する。

## 文脈の導入

`$let`・`$std.state`・`$with` は、`$in` を省いて頭だけを書くと、それを置いた並びの残りに文脈を導入する（[言語仕様の文脈の導入の節](../grammar.md)）。
`$do` の文で導入した文脈の本体は、残りの文の並びである。
先に置いた頭ほど外側になり、最後の文で導入した文脈の本体は null である。
文脈として導入される `$let` の束縛と、`$with` のローカル作用の宣言の束縛は、残りの文から参照できる。

## 展開

意味は次の展開で定める。
規則は上から順に、最初に一致したものを適用する。
私的名は文書から参照できない捨て名である。

```
{$do: []}                              ≡ null
{$do: [{$let: 束縛}, 残り...]}         ≡ {$let: 束縛, $in: {$do: [残り...]}}
{$do: [{$std.state: 初期値}, 残り...]} ≡ {$std.state: 初期値, $in: {$do: [残り...]}}
{$do: [{$with: 節}, 残り...]}          ≡ {$with: 節, $in: {$do: [残り...]}}
{$do: [結果]}                          ≡ 結果
{$do: [文, 残り...]}                   ≡ {$let: {私的名: 文}, $in: {$do: [残り...]}}
```

`$in` や残りを伴う完結した式は文脈の導入の規則に一致せず、最後の規則で通常の文になる。
頭を交互に重ねる列は、マッピングでは各頭キーを一つずつしか置けないので、`$do` の文でだけ書ける。

## 例

```yaml
$do:
- $std.log: starting
- hello, world
```

```yaml
hello, world
```

文に置いた `$with` で失敗を捕捉する。

```yaml
$do:
- $with:
    std.fail: {$fn: _, $body: 0}
- $std.lookup: {in: {}, key: missing}
```

```yaml
0
```

文に置いた `$std.state` と `$let` を組み合わせる。

```yaml
$do:
- $std.state: {n: 0}
- $std.set: {n: 41}
- $let:
    n: {$std.get: n}
- ${n + 1}
```

```yaml
42
```
