# $do

`$do` は文の並びを先頭から順に評価するブロックである。
[$let](let.md) への展開で定まる導出形であり、カーネルには属さない。

- 種別：束縛と制御（導出形）

## 形

```yaml
$do:
- 文1
- 文2
- 結果式
```

## 規則

- 直下のリストを文の並びとして先頭から評価し、最後の文の値をブロックの値とする。最後の文を除き、文の値は捨てられる。
- 「リストはデータ」の唯一の例外がこの直下のリストである。文の位置に書いた literal なリストは、通常どおりデータとして評価される。
- 空の `$do` の値は null である。
- 文には任意の式のほか、`$in` を省いた `$let` と演算を置く。`$std.where` と `$std.set` と `$std.log` の値は null であり、この位置に置くのがなじむ。
- 入れ子の `$do` は作用境界にならず、単なるグループ化である。文が起こした作用は最も外側の `$` 式まで伝播する。

## 展開

意味は次の展開で定める。
規則は上から順に、最初に一致したものを適用する。
私的名は文書から参照できない捨て名である。

```
{$do: []}                      ≡ null
{$do: [{$let: 束縛}, 残り...]} ≡ {$let: 束縛, $in: {$do: [残り...]}}
{$do: [結果]}                  ≡ 結果
{$do: [文, 残り...]}           ≡ {$let: {私的名: 文}, $in: {$do: [残り...]}}
```

## 例

```yaml
$do:
- $std.log: starting
- hello, world
```

```yaml
hello, world
```
