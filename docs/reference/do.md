# $do

`$do` は文の並びを先頭から順に評価するブロックである。
[$let](let.md)・[$for](for.md)・[$handler](handler.md) への展開で定まる導出形であり、カーネルには属さない。

- 種別：導出形（文の並び）

## 構文

```yaml
$do:
- 文1
- 文2
- 結果式
```

## 規則

- 直下のリストを文の並びとして先頭から評価する。最後の文の値をブロックの値とし、それ以外の文の値は捨てる。
- 「リストはデータ」の唯一の例外がこの直下のリストである。文の位置に書いた literal なリストは、通常どおりデータとして評価される。
- 空の `$do` の値は null である。
- 文には任意の式のほか、文脈の導入（`$in` を省いた `$let`、`$for`、`$handler`）と呼び出しを置く。`std.where` と `std.set` と `std.log` の値は null であり、この位置に置くのがなじむ。YAML には unit 型がないため、値を返さないことを表すには null を unit の代用とする。
- 入れ子の `$do` は作用境界にならず、単なるグループ化である。文が起こした作用は最も外側の `$` 式まで伝播する。

## 文脈の導入

`$let`・`$for`・`$handler` は、`$in` を省いて頭だけを書くと、それを置いた並びの残りに文脈を導入する（[言語仕様の文脈の導入の節](../grammar/derived.md)）。
`$do` の文で導入した文脈の本体は、残りの文の並びである。
先に置いた頭ほど外側になり、最後の文で導入した文脈の本体は null である。
文脈として導入される `$let` の束縛と、`$handler` のローカル作用の宣言の束縛は、残りの文から参照できる。
頭を交互に重ねる列は、マッピングでは各頭キーを一つずつしか置けないので、`$do` の文でだけ書ける。

## 展開

意味は次の展開で定める。
規則は上から順に、最初に一致したものを適用する。
内部名は処理系内部の捨て名であり、文書から参照できない。

```
{$do: []}                            ≡ null
{$do: [{$let: 束縛}, 残り...]}       ≡ {$let: 束縛, $in: {$do: [残り...]}}
{$do: [{$for: 束縛}, 残り...]}       ≡ {$for: 束縛, $in: {$do: [残り...]}}
{$do: [{$handler: 式}, 残り...]}     ≡ {$handler: 式, $in: {$do: [残り...]}}
{$do: [結果]}                        ≡ 結果
{$do: [文, 残り...]}                 ≡ {$let: {内部名: 文}, $in: {$do: [残り...]}}
```

`$in` や残りを伴う完結した式は文脈の導入の規則に一致せず、最後の規則で通常の文になる。

## 例

```yaml
$do:
- $std.log: starting
- hello, world
```

```yaml
hello, world
```

文に置いた `$handler` で失敗を捕捉する。

```yaml
$do:
- $handler:
    std.fail: {$fn: _, $body: 0}
- $std.lookup: {in: {}, key: missing}
```

```yaml
0
```

文に置いた状態のハンドラと `$let` を組み合わせる。

```yaml
$do:
- $handler: {$std.state: {n: 0}}
- $std.set: {n: 41}
- $let:
    n: {$std.get: n}
- ${n + 1}
```

```yaml
42
```
