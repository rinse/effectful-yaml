# カーネルと導出形

言語が意味を直接与える構文、すなわちカーネルは次の 5 形である。

| カーネル | 書き方 |
|---|---|
| 参照と式 | `${...}` |
| 束縛と逐次 | `$let`（`$in`） |
| 分岐 | `$if`（`$then` `$else`） |
| 関数と呼び出し | `$fn`（`$body`）、`{$パス: 引数}` |
| ハンドラ | `$handler`（`$in` `$resume`） |

残る形は導出形であり、意味はカーネルへの展開で定める。

| 導出形 | 展開を定める節 |
|---|---|
| 文の並び `$do` | `$do` |
| `$in` を省いた頭 | 文脈の導入 |
| 選択の束縛の頭 `$for` | `$for` |
| 既定値の補助キー `$default` | `$default` |
| `$fn` の引数名の列 | `$fn` |

`std` の演算と関数の意味も、カーネルへの展開か、値から値への規則で定まる。
展開が規範であり、処理系は等価な組み込みで最適化してよいが、観測できる振る舞い（値、作用、ログの順序）は展開と一致しなければならない。

`$in` の役割はどの形でも変わらない。
`$in` は常に本体、すなわちその形がスコープを及ぼす計算を導く。

畳み込みの構文はカーネルにない。
構造を回る反復は `std` の関数 `std.collect` が与える。
