# 作用の伝播

## 作用境界

データの中に現れた最も外側の `$` 式を作用境界と呼ぶ。
境界の内側で演算が起こす作用は、途中にハンドラがなければ境界まで伝播し、そこで処理系の既定ハンドラが処理する。
入れ子の `$` 式は境界にならないので、`$do` の中の `$do` は単なるグループ化である。

境界が互いに独立であることには意味がある。
兄弟関係にある二つの境界は作用を共有しないので、データ部分の評価は順序に依存しない。
複数の場所で状態や選択を共有したければ、その範囲全体を一つの `$do` で包み、単一の境界にする。

## 合成・部分処理・境界

作用境界がどこに生じるかは、構文上の位置ごとに三つに分かれる。

| 位置 | 作用の行き先 |
|---|---|
| 合成 | 内側で起きた作用が周囲の計算へそのまま合流する |
| 部分処理 | ハンドラが節に挙げた演算だけを取り除き、残りは透過する |
| 境界 | 残るすべての作用を既定ハンドラの系列で処理し尽くす |

合成の位置は、`$let` の右辺から後続の束縛と `$in` の本体への流れ、`$do` の文の並び、`$if` の選ばれた分岐、呼び出しの引数と本体、`std.collect` の対象と関数本体、そして境界の内側に現れるデータ構成（リストの要素、`$` キーを持たないマッピングの値）である。
データ構成は作用を起こさないが、遮りもしない。
演算は `$` 式の引数の中であればどこにでも置ける。

```yaml
$do:
- $handler: ${std.list}
- - 1
  - {$std.each: [a, b]}
```

```yaml
[[1, a], [1, b]]
```

リストの要素に置いた選択が外側のブロック全体を 2 通りに分岐させる。
`$let` の右辺に `$std.each` を書くと包囲する逐次の全体が分岐するのも、関数呼び出しの作用が「引数の作用と本体の作用の合併」になるのも同じ理由による。
`$if` も合成なので、選ばれた分岐の選択だけが周囲へ合流する。
`$then` にだけ選択が現れる `$if` は、`$else` 側が選ばれれば選択を起こさない。

部分処理の位置はハンドラである。
節に挙げていない作用はそのまま透過し、ハンドラ自身の値へ合流する。
既定の状態が選択をまたいで貫流するのは、既定の状態ハンドラが境界にあり、文書内のどの選択のハンドラよりも外側だからである。

境界は、作用境界の節で定めたとおり、データの中に現れた最も外側の `$` 式と、文書全体である。
境界に達した計算は、残るすべての作用を処理し尽くしてから、初めて具体的な値になる。
境界の内側には、明示のハンドラを除いて作用を堰き止める場所はない。

## 引数の評価順

呼び出しは、引数を評価してから、関数なら本体の評価に、演算なら作用に進む（値渡し）。
引数の評価で起きた作用は堰き止められず、周囲へ合流する。
`{$.f: {$std.each: [1, 2]}}` は、引数の選択が周囲へ合流するので、`f` の呼び出しごと分岐する（`f` が 1 回で `[1, 2]` を受け取るのではない）。
本体を評価する前にハンドラを立てたいときは、値渡しの呼び出しではなく `$handler` の `$in` に本体を書く。

`$default` の式は例外で、`$if` の分岐と同じ遅延位置である。
本体が失敗しなければ `$default` は評価されず、その作用も起きない。

## 既定ハンドラ

境界に達した作用は、処理系が文書を `std` の既定ハンドラの系列で包んだものとして処理される。
系列は外側から失敗、パラメータ、ログ、状態の順である。

| 既定ハンドラ | 処理 |
|---|---|
| 失敗 | 捕捉されずに届いた `std.fail` は、その値をメッセージとして文書全体のエラーになる |
| パラメータ | `std.param` は起動時に与えられたパラメータ表を読む |
| ログ | `std.log` は値をホストのログ出力に流す |
| 状態 | 暗黙の `$handler: {$std.state: {}}` が置かれる |

状態の既定ハンドラは境界にあるので文書内のどの選択のハンドラよりも外側であり、状態は分岐をまたいで文書順に貫流する。
この振る舞いを変えたいときは `std.state` を明示的に置く。

ホストが与えた演算には、ホストの実装が既定ハンドラとして付いている。
選択（`std.each`）と、ローカル作用の宣言が作った演算には既定ハンドラがない。
境界へ達した選択は `unhandled choice` のエラーになり、境界へ達したローカル作用は脱出のエラーになる。
選択を値にするのは、それを処理する明示のハンドラ（`std.each` の節を持つ `$handler`、およびそれを立てる `std.list`・`std.mapping`・`std.first`）だけであり、そのハンドラの形が値の形を決める。
